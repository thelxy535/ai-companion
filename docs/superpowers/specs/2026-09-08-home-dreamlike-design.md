# 首页「夜航星环」视觉设计

## 目标

让弦曜 SYLORA 的首页更像一个怀揣梦想的创作者亲手做出的陪伴空间：有夜航感、有温度、有自己的审美，但仍然让用户一眼看懂消息状态并快速进入聊天。

## 设计方向

首页采用「夜航星环」作为视觉主题。页面不是信息仪表盘，而是一张安静的夜间联络图。标题负责建立情绪，角色卡负责承载行动，星环与光点只作为低对比度空间线索。

## 视觉结构

- 顶部标题使用轻叙事语气，保留角色总数和在线数作为辅助信息。
- 内容区增加低对比度的轨道线和星点，使用裁切在内容范围内，不能遮挡文字或造成大面积装饰噪声。
- 角色卡继续使用玻璃质感，但通过角色头像的专属光环色保留个体差异。
- 未读消息继续沿用现有状态计算，视觉上使用主色文字、细小光点和轻微强调，不引入红点。
- 空状态使用“还没有哪颗星亮起，去认识一个人吧”一类的文案，并保留明确的“开始聊天”入口。

## 动效

- 首次进入保留现有错峰上浮，作为一次性入场。
- 星环只做缓慢、低幅度的透明度呼吸；不循环移动整块内容，不在每次返回首页时制造强烈动画。
- 动画不参与数据状态判断，降低重组和耗电风险。

## 交互与边界

- 不修改 `HomeViewModel`、消息查询、未读时间戳或数据库结构。
- 有角色、未读消息、无角色、加载中和失败状态都必须有可读的布局。
- 文案和轨道装饰必须在 320dp 宽度下不裁切关键内容。
- 保留现有头像点击、角色跳转、预热缓存和底部导航行为。

## 验收标准

1. 首页第一眼能感知“夜航星环”主题，但不会像营销页或仪表盘。
2. 用户能在一秒内识别有无新消息、角色是否在线和最近消息。
3. 角色之间仍有明显个体差异，不被统一的装饰覆盖。
4. 模拟器在小屏、常规尺寸和三种数据状态下无重叠、无横向溢出。
5. 单元测试、Lint 和 Debug APK 构建通过。
