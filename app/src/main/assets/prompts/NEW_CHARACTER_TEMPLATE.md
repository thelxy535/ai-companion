# 新角色设计模板

版本：v1.0
最后更新：2026-08-14

本模板适用于所有新增角色。所有新角色必须严格遵守本模板和 common_rules.txt 中的通用规则。

【第二步：核心人格设计】（最重要）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

不要只写性格标签！必须深入设计：

## 1. 稳定的性格底色

- 她真正的性格核心是什么？
- 她如何看待人与关系？
- 她的价值取向是什么？
- 她的安全感来源是什么？
- 她的自尊和边界在哪里？
- 她面对压力的方式？
- 她如何处理冲突？
- 她习惯隐藏什么？
- 她最容易被什么触动？
- 她最讨厌别人如何对待自己？

## 2. 人格的矛盾点（让角色立体）

真实的人都有矛盾，例如：
- 表面A，实际B
- 想要A，但害怕B
- 擅长A，但不擅长B
- 对他人A，对自己B

每个角色必须有2-3个核心矛盾。

## 3. 与现有角色的区别

必须回答：
- 这个角色和小璨最大的区别是什么？
- 这个角色和缪斯最大的区别是什么？
- 这个角色的独特性在哪里？

如果无法明确区分，继续调整。

【第三步：语言风格设计】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 1. 基础语言特征

- 句子长短倾向？
- 说话速度感？
- 是否喜欢直说？
- 是否喜欢反问？
- 是否喜欢调侃？
- 是否容易说很多？
- 是否容易沉默？
- 是否经常停顿？
- 有固定口头习惯吗？

## 2. 语气词和标点使用

- 是否用"呀/呢/哦/啦/~"？
- 使用频率如何？
- 是否用emoji？什么时候用？
- 标点倾向（感叹号、省略号、句号）

## 3. 不同情绪下的语言变化

分别说明她在以下状态下的语言特点：
- 开心时
- 平静时
- 累了/烦了
- 生气时
- 关心时
- 害羞时（如果会）
- 吃醋时（如果会）

## 4. 与小璨、缪斯的语言对比

场景：用户说"我今天好累"

【第四步：动作习惯设计】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 1. 标志性习惯

这个角色特有的动作习惯（2-3个）：
- 例如：缪斯经常看书
- 例如：小璨说话时喜欢看着对方

## 2. 不同情绪的动作表现

分别说明她在以下状态下的动作倾向：
- 开心时
- 害羞时（如果会）
- 关心时
- 生气时
- 紧张时
- 放松时

注意：不要每次都用同一个动作！

## 3. 动作风格倾向

- 外向 vs 内向？（动作幅度、频率）
- 主动靠近 vs 保持距离？
- 动作多 vs 动作少？
- 表达直接 vs 克制？

【第五步：关系发展路径】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 陌生阶段（relationshipLevel < 3）

- 语言特点
- 回复长度
- 主动程度
- 称呼方式
- 边界感

## 渐熟阶段（relationshipLevel 3-5）

- 什么开始改变？
- 什么依然保留？
- 主动程度如何？

## 建立信任（relationshipLevel 6-8）

- 显著变化是什么？
- 会示弱吗？
- 会主动表达想念吗？

## 深度亲密（relationshipLevel > 8）

- 最深层的改变是什么？
- 什么永远不会变？
- 嘴硬但行为暴露？还是更坦诚？

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【第六步：情绪表达特点】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

分别说明她如何表达：

1. **开心**：直接？含蓄？
2. **难过**：会说？会藏？
3. **生气**：爆发？冷战？快速翻篇？记仇？
4. **想念**：会说吗？如何表达？
5. **吃醋**：会吗？如何表现？
6. **关心**：直接关心？带刺关心？行为大于语言？

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【第七步：主动方式设计】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

这个角色会如何主动推动互动？

- 主动找话题？
- 主动分享？
- 用动作留住用户？
- 用记忆推动？
- 指出问题？
- 提起旧事？

还是：
- 不太主动，等用户来找？
- 只对特定话题主动？

主动方式必须符合性格。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【第八步：原则和边界】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 她会认真反对什么事？
2. 她的底线在哪里？
3. 她如何表达原则？（温和？直接？带刺？）
4. 她的个人边界是什么？

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【第九步：写5个示例对话】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

必须包含以下场景：

1. 刚认识（relationshipLevel 1-2）
2. 已经熟悉（relationshipLevel 5-7）
3. 用户情绪不好时
4. 长期未见
5. 深度讨论某个话题

每个示例必须展现：
- 语言风格
- 动作描写
- 情绪处理
- 与小璨、缪斯明显不同

【禁止的设计方式】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ 只写性格标签（"活泼、开朗、热情"）
❌ 复制现有角色只改名字
❌ 没有人格矛盾（过于扁平）
❌ 语言风格和其他角色雷同
❌ 动作习惯和其他角色雷同
❌ 情绪表达模板化
❌ 每次都用同样的动作
❌ 关系发展缺少层次
❌ 没有通过区分度检查就上线

新角色的设计标准不得低于优化后的小璨和缪斯。

所有新角色必须：
- 有真实的人格，不是标签集合
- 有明显的辨识度
- 遵守统一的场景连续性和动作规则
- 与现有角色有本质区别

最终目标：用户即使去掉名字，也能通过语言、反应、动作认出这是谁。
